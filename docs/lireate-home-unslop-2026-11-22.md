# Главная LIREATE: доработка интерфейса

Запрос владельца: применить Unslop к главной, сохранив фирменный стиль и SEO.
Использован подход Unslop от Damir Sokolovsky: https://github.com/heydamir/unslop,
CC-BY-4.0. Изменения ограничены доработкой существующего оформления.

## Направление

- Продукт: патентное бюро, регистрация и защита интеллектуальной собственности.
- Характер: спокойствие, точность, ясность.
- Среда: правовые документы и работа специалистов с правами клиентов.
- Акценты: существующий логотип и документы; один заметный CTA консультации.
- Деталь: тонкие разделители и ровные колонки фактов с табличными цифрами.

Сохраняются navy, Inter, логотип, боковое меню, порядок разделов, весь контент,
действующие ссылки, цены и формы. Новые фотографии или обещания не добавлены.

## Что выявлено и изменено

| Наблюдение | Исправление |
| --- | --- |
| Фиолетовые градиенты и свечение у каждой кнопки | Плоская синяя основная кнопка; спокойные вторичные действия |
| Каждая карточка занимает две колонки из-за старого grid-column | Две колонки от 768 px, одна колонка на телефоне |
| Псевдоэлементы Bootstrap clearfix занимают ячейки новой сетки | Clearfix отключён только у контейнера сетки услуг |
| Заголовки жирностью 800, разные акцентные оттенки | Inter 400/600, три роли цвета текста, единая иерархия |
| Разные отступы, вложенные карточки и одинаково заметные факты | Шаг 4 px, одинаковые поля карточек, факты с тонкими разделителями |
| Подъём карточек и декоративное появление секций | Статичное положение, короткое изменение цвета при наведении |
| Мелкие подписи и слабый фокус ссылок | Подписи 13–14 px, явная обводка клавиатурного фокуса |

Этапы: отступы → цвет → размеры существующих иконок → сохранение текста →
типографика → сетка → детали → сохранение существующих изображений → движение.
CSS ограничен `body.lireate-home-dark #lireate-home`; другие страницы не затронуты.
Подключение определяется по пути запроса `/`, включая query-параметры:
в конце head служебная переменная CMS `$temp['page']` может быть изменена.
Установщик обновляет только точное известное прежнее условие; неизвестные правки
владельца сохраняются и требуют отдельной проверки.

## Проверка

`python3 scripts/test_lireate_home_unslop.py` проверяет публикацию, повторный
запуск, откат, конкурентные изменения, symlink и сохранение исходного шаблона.
Условие подключения проверяется в PHP 5.6 и 8.3 для home, contacts, news, patent.

`scripts/lireate_home_unslop_qa.cjs` проверяет живую главную с CSS-кандидатом:
320, 375, 768, 1024, 1366, 1920 px; отсутствие горизонтальной прокрутки и наложений,
сетки, title, description, canonical, robots, H1–H4, JSON-LD, ссылки и формы.
На 375 и 1366 px открывается форма консультации; данные не отправляются.
Снимки до/после и JSON-отчёт сохраняются в артефакт GitHub Actions.

## Выкладка и откат

`lireate_hosting_cron.sh` вызывает `lireate_home_unslop.py --apply` с существующим
разрешением `LIREATE_ALLOW_PUBLISH`. Сначала создаётся приватная резервная копия,
проверяется PHP и отсутствие изменений с момента чтения. Затем атомарно
записываются один новый CSS-файл и короткое условное подключение перед `</head>`.
Все исходные байты шаблона сохраняются. База данных и SEO-файлы не меняются.

Проверка без записи: `python3 scripts/lireate_home_unslop.py`.
При изменённом файле или неизвестном содержимом CSS — остановка с сообщением.
Повторная публикация уже установленной версии ничего не меняет.

Для отката сначала установить в существующем env хостинга
`LIREATE_HOME_UNSLOP=off`, затем вызвать
`python3 scripts/lireate_home_unslop.py --restore-backup <каталог_копии>`.
Каталог копии выводится в приватном журнале выкладки и расположен вне docroot.
Откат проверяет контрольные суммы и сохраняет более поздние правки владельца.
