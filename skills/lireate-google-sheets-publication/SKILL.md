# Навык: Google Sheets — журнал статей Лирейт

## Обязательный триггер
После **успешной** публикации статьи в CMS сайта lireate.ru и подтверждения HTTP 200 публичного URL вызвать `scripts/lireate_sheets_sync.py`. Обязателен и для повторного запуска CRON при ранее опубликованной статье, если её синхронизация не завершена.

Не записывать черновики, неподтверждённые URL, предпросмотры, ошибки публикации или статьи на другом домене. Запись в Google Sheets не должна отменять уже успешную публикацию на сайте.

## Целевая таблица
Google Sheets `lireate_blog_articles`, вкладка `Статьи блога`; исходные колонки:
- A: `№` — последовательный номер, рассчитывает сервер таблицы по последней числовой строке.
- B: `Название` — фактический заголовок опубликованной статьи.
- C: `Ссылка` — проверенный URL на lireate.ru.
- D: `О чём статья` — 1–3 человеческих предложения, краткое содержание без выдуманных фактов, без HTML и SEO-воды.

Сохранить существующие 251 строку данных. Не менять названия столбцов, не стирать старые строки. Дедупликация по нормализованному URL (с/без конечного слэша), повторная отправка обновляет только B и D существующей строки, если это включено на сервере, не добавляет новый номер.

## Интеграция
REG.RU shared hosting → HTTPS POST в развернутый Google Apps Script Web App → Google Sheets API через SpreadsheetApp.

Настройка: `docs/lireate-sheets-setup.md`. Секреты на хостинге в `.env`:
- `LIREATE_SHEETS_WEBHOOK_URL` (URL `/exec` развернутого Apps Script)
- `LIREATE_SHEETS_WEBHOOK_SECRET` (случайная строка ≥32 символов)

Секрет приложения в Apps Script Properties `WEBHOOK_SECRET`, ID исходной таблицы в `SPREADSHEET_ID`, имя листа `SHEET_NAME=Статьи блога`. Не публиковать секреты или токены в GitHub и логах.

Скрипт создает JSON в устойчивом локальном outbox; если сеть недоступна, сохраняет событие для повторной отправки на следующем CRON. Ключ идемпотентности — canonical URL. Все ошибки журналируются без секретов.

## Проверка
1. Публикация подтверждена: verdict=published, live_url_http_after=200.
2. Файл `lireate-publish-result.json` сохраняет `sheets_sync` со статусом.
3. Новая статья появляется ровно один раз, в колонках A:D, существующие строки не изменены.
4. Ошибка Sheets не превращает успешную публикацию на сайте в ошибку; outbox повторяется на последующих запусках.
5. `--dry-run`: никаких изменений в Google Sheets.

Нельзя заявлять, что Google Sheets обновлена, пока не получен ответ `ok:true` от Apps Script.
