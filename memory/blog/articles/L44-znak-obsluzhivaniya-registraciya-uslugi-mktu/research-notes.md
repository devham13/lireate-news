## 4. Угол и дифференциация

**Главный угол:** **сравнение без мифов** (одна процедура, одно свидетельство, различие — **объект** и **классы 35–45**) + **мини-матрица выбора классов** для трёх типов ИП (салон → 44/35; кофейня/общепит → 43; онлайн-школа → 41; IT-сервис → 42) с отсылкой к **L06** за точными формулировками из МКТУ-13.

## 5. action_outline (comparison + выбор классов для услуг)

1. **Опишите модель бизнеса:** вы **только оказываете услуги**, **продаёте товары**, или **и то и другое** (салон + своя косметика, кофейня + зерно под брендом).
2. **Сверьте термины с ГК РФ:** п. 1–2 **ст. 1477** — знак обслуживания это не «другая регистрация», а охрана **услуг/работ** в тех же правилах, что и ТЗ.
3. **Разметьте классы МКТУ:** услуги — **35–45**; товары — **1–34**; выпишите черновик классов под **фактическую** и **планируемую** деятельность (не «на вырост» без намерения использовать).
4. **Подберите формулировки в МКТУ-13:** для каждого класса возьмите **официальные наименования услуг** из [ФИПС / классификатора](https://online.rospatent.gov.ru/open-data/classifiers/product-classifiers); детальный алгоритм — **L06**.
5. **Пройдите типовой чек для ИП:** салон (база **44**, часто **35**; **3** при своей косметике); кофейня (**43**, иногда **35**); онлайн-курсы (**41**); разработка ПО / SaaS (**42**).
6. **Проверьте обозначение:** бесплатный поиск в [Поисковой платформе](https://searchplatform.rospatent.gov.ru/trademarks) по выбранным **услуговым** классам и смежным (корреспондирующим); чек-лист — **L01**.
7. **Оцените охраноспособность:** избегайте чисто описательных названий («Парикмахерская», «Beauty» без различительных элементов) — **ст. 1483**; при сомнении — платная оценка ФИПС (46 200 ₽ / 1 класс) или поверенный.
8. **Подготовьте заявку с учётом 18.08.2026:** актуальная **форма заявки** (приказ № 386); перечень услуг **по классам**, не «весь класс 44» без позиций.
9. **Заложите бюджет пошлин по классам:** [таблица Роспатента](https://rospatent.gov.ru/ru/activities/dues/table) и правила ПП № 1459; полный цикл подачи — **L30**.
