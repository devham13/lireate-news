## action_outline (7 шагов)

1. **Проверить ЕРВК:** по ИНН и ОКВЭД — есть ли обязательное уведомление о начале деятельности; при отсутствии — подать через Госуслуги до любых операций с вводом (актуально с 01.03.2026 по официальным страницам сообщества и Роспотребнадзора).  
2. **Национальный каталог:** карточка товара с корректным **GTIN** и атрибутами; убедиться, что заказ КМ будет с сценарием **«Ввезен в РФ»**.  
3. **Лицевой счёт → заказ КМ → получение кодов:** при необходимости импорт XML в СУЗ; не превысить лимиты GTIN/КМ на заказ.  
4. **Нанесение и отчёт о нанесении** в сроки, зависящие от маршрута (ЕАЭС / не ЕАЭС), затем таможенное оформление с корректным заполнением **графы 31** ДТ по правилам ФТС.  
5. **После выпуска товара** подать **«Ввод в оборот. Импорт с ФТС»** (для внешнего импорта), дождаться обработки и статусов кодов.  
6. **Если ошибка обмена с ФТС** (например, `FtsGoodsReleaseMarkRes_orh` / attachment): сохранить **ID документа**, **XML**, скриншот; направить в **support@crpt.ru**; при предложенном в ЛК **ручном** заполнении полей по коду — заполнить **страну происхождения** и **ТН ВЭД** и повторить отправку.  
7. **Если неверный вид документа ввода** — не дублировать ввод по тем же КМ; уточнить в ЛК/у поддержки сценарий **корректировки** для своей ТГ и зафиксировать внутренний регламент двойной проверки перед отправкой.

После гайда читатель сможет **сверить цепочку импорта (НК → заказ «ввезен в РФ» → нанесение → ДТ → ввод с ФТС)**, **заранее устранить типичные причины отказов (ЕРВК, графа 31, неверный вид документа)** и **пошагово отреагировать на распространённые ошибки обмена с ФТС без выдуманных «правок» черновика**.
