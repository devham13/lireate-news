## 5. action_outline

1. Зафиксировать варианты обозначения (слово, транслит, комбинированный макет) и список товаров/услуг.
2. Подобрать классы и формулировки по **МКТУ-13–2026** (классификатор Роспатента / ФИПС).
3. **Поисковая платформа:** текст/звук/смысл + фильтр классов; для лого — загрузка изображения; сохранить номера знаков и **заявок**.
4. **Открытые реестры ФИПС:** статус по каждому номеру; отдельно **реестр заявок**.
5. **Международный контур:** TMview + реестр мадридских знаков на ФИПС.
6. **Черновая оценка сходства** (звук, смысл, графика) по каждому близкому результату.
7. **Однородность** перечней; при сомнении — лексико-семантический идентификатор.
8. **Абсолютные риски** по п. 1–3 ст. 1483 ГК РФ.
9. **Вне реестров:** ЕГРЮЛ, домены, маркетплейсы; решение — доработка / сужение классов / предоценка ФИПС / поверенный.
