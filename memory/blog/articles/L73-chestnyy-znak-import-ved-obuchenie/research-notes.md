## 2. Угол L73: ВЭД vs юрист / бренд (RACI, не дублировать L67)

**Суть отстройки:** не «как пройти импорт с нуля» (L67), не «чек-лист владельца бренда: ЧЗ + ТЗ + ТРОИС» (L22), не «исправить сниппет / ошибки ФТС» (L36). L73 — **краткий учебный маршрут** (onboarding) для **менеджера ВЭД**: зоны ответственности и **контрольные точки до передачи пакета на таможенное оформление**.

| Роль | Зона ответственности при импорте маркированного товара | Типичные артефакты |
|------|--------------------------------------------------------|--------------------|
| **Менеджер ВЭД** | ТН ВЭД в спецификации; сверка количества в инвойсе/упаковочном листе с заказом КМ; передача кодов на производство; **транспортные документы** (CMR, коносамент, авианакладная, ТТН); подготовка **файла КИ для графы 31** декларанту; контроль статуса КМ «Нанесён»; календарь «до подачи ДТ» | Excel/CSV КМ, CMR, инвойс, packing list, договор поставки |
| **Юрист / комплаенс** | Договор импорта; **разрешительная документация** (ДС/СС), графа 44 ДТ; при своём бренде — **регистрация ТЗ**, **ТРОИС**; **ЕРВК** / уведомления о деятельности (с 01.03.2026 — проверка при операциях в ГИС МТ, см. L36); споры с контрагентом | Контракт, ДС/СС, выписки реестров |
| **Бренд / категорийный менеджер** | Наименование и **поле «товарный знак»** в Национальном каталоге; соответствие этикетки фактическому обозначению; связка с **reg-tz** при запуске нового имени | Макет этикетки, GTIN-атрибуты |
| **Бухгалтерия / финансы** | Оплата лицевого счёта ЦРПТ; пополнение под заказ КМ; после выпуска — учёт ввода в оборот | Платёж ЦРПТ, УПД с кодами (после оборота) |

**Правило для writer:** в lead зафиксировать: обучение ВЭД **не заменяет** курс ПК на 72 часа и **не учит** регистрировать товарный знак — за ТЗ отвечает юрист/бренд (**L22**).

## 6. action_outline (mode B — маршрут обучения, 9 модулей)

1. **Модуль 0 — RACI:** распределить зоны ВЭД / юрист / бренд; зафиксировать ответственного за ЛК «Честный знак» и за подписание ЭДО.  
2. **Модуль 1 — ТН ВЭД и группа маркировки:** по спецификации взять **10-значный ТН ВЭД** и **ОКПД2**; проверить обязательность на [сервисе честныйзнак.рф](https://честныйзнак.рф/checking_codes/) (календарь ТГ — [crpt.ru/news](https://crpt.ru/news/)); при сомнении — эскалация юристу, не заказ КМ.  
3. **Модуль 2 — Национальный каталог:** совместно с брендом заполнить **GTIN**, полное наименование, **товарный знак на этикетке**; сверить с **L22** при своём бренде.  
4. **Модуль 3 — Заказ и логистика кодов:** заказ КМ **«Ввезен в РФ»**; выбрать площадку нанесения (завод / склад вне РФ / таможенный склад); **запрет СВХ** без УЭО; передать производителю файлы + **инструкцию по Data Matrix**.  
5. **Модуль 4 — Транспортные документы:** до отгрузки сверить **количество мест и артикулов** в инвойсе, packing list и CMR с числом **эмитированных и нанесённых КМ**; зафиксировать расхождения **до** границы.  
6. **Модуль 5 — Контроль перед таможней:** в ЛК — статус **«Нанесён»**; выгрузить перечень КИ; для каждой **строки ДТ** — один ТН ВЭД; подготовить **КИТУ** при смешанных логистических единицах (см. официальные правила гр. 31).  
7. **Модуль 6 — Пакет декларанту:** передать брокеру контракт, инвойс, транспортные документы, ДС/СС, **файл КИ**; чек-лист «нет дубля КИ в разных строках».  
8. **Модуль 7 — После выпуска (не ВЭД solo):** юрист/оператор ГИС МТ подаёт **«Импорт с ФТС»** с корректным номером ДТ; ВЭД сверяет, что количество выпущенных = введённых. Ошибки — **L36**.  
9. **Модуль 8 — Закрепление:** внутренний одностраничный регламент + ссылка сотруднику на **L67** (база) и **L22** (бренд); при найме — опционально внешнее ПК 72 ч. только для сертификации компетенций.
