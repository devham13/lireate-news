## 4. Угол и дифференциация

**Главный угол:** «**Структура → поиск → проверка пояснений → смежные классы → черновик перечня**» на примере МКТУ-13–2026: читатель за 30–60 минут получает **класс и официальную формулировку** для своего товара/услуги и понимает, когда добавить **второй класс** или проверить **корреспондирующий**.

**Отличие от конкурентов:** не энциклопедия всех 45 классов, а **алгоритм** + мини-кейсы из семантики темы (**вареники → 30**, **ювелирка/часы → 14 vs 9**, **ковры → 27 vs 19/24**); явное предупреждение про ложный SERP «класс 27»; связка с **L01** (поиск после подбора).

**Тон Lireate:** патентные поверенные; без обещания «100% регистрации»; CTA — консультация по подбору классов / регистрация ТЗ.

## 5. action_outline (how-to: определить класс МКТУ)

1. **Соберите входные данные:** точное название товара/услуги, как вы его продаёте (B2C/B2B), планируемые каналы (офлайн, маркетплейс, SaaS), есть ли **сопутствующие** товары (упаковка, софт, монтаж).
2. **Определите тип позиции:** **товар (классы 1–34)** или **услуга (35–45)**; для гибрида (например, доставка готовой еды) заложите **отдельный проход** по каждому виду деятельности.
3. **Откройте действующую редакцию:** [ФИПС МКТУ-13–2026](https://www.fips.ru/publication-web/classification/mktu/static?page=klassifikatsiya-tovarov-i-uslug-mktu-13-2026-g-) или [классификатор Роспатента](https://online.rospatent.gov.ru/open-data/classifiers/product-classifiers); не используйте устаревшие PDF 11-й редакции с чужих сайтов.
4. **Сформулируйте 2–4 ключевых слова** для поиска (например, «вареники», «ковры», «наручные часы»); найдите позицию в **алфавитном перечне**, выпишите **номер класса**, **базовый номер** и **полную формулировку** (со скобками).
5. **Прочитайте пояснение класса:** блоки «относится» / «**не относится**» — зафиксируйте, не попали ли вы в соседний класс (паркет 19 vs линолеум 27; умные часы 9 vs часы 14).
6. **Проверьте корреспондирующие классы** по таблице из Рекомендаций (например, 29–30 для пищевых продуктов) и при необходимости добавьте **второй класс** в черновик перечня, если реально планируете такую линейку.
7. **Избегите типичных ошибок:** указать только заголовок класса; скопировать чужой перечень из интернета; взять формулировку из **МКТУ-11/12** без сверки с МКТУ-13; пропустить **услуги** (кл. 35 при торговле брендом).
8. **Сверьте черновик перечня** с однородностью и конкурентами: бесплатный поиск в [Поисковой платформе](https://searchplatform.rospatent.gov.ru/trademarks) по выбранным классам (детальный чек-лист — **L01**).
9. **Зафиксируйте итог в таблице** «класс | базовый номер | формулировка из МКТУ-13 | обоснование (1 предложение)»; при сомнении — платная предварительная оценка ФИПС (1 класс) или консультация поверенного.
