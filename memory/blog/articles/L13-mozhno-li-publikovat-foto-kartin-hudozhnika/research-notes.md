## 4. Угол и дифференциация

**Главный угол:** **чек-лист из двух слоёв** — (А) охраняется ли **картина**, (Б) охраняется ли **ваш файл** (своя съёмка, скан музея, чужое фото) — плюс **цель публикации** и **условия площадки/музея**.

**Дерево решений для writer:**

| Ситуация | Базовое правило | Что проверить в чек-листе |
|----------|-----------------|---------------------------|
| Картина **старше 70 лет** после смерти автора | Общественное достояние (ст. 1281–1282) | Имя автора, корректная атрибуция; отдельно — **файл** (см. ниже) |
| **Современный** художник, работа под AP | Нужны **согласие/лицензия** или законное ограничение (1274, 1276) | Кто правообладатель; коммерция vs обзор выставки |
| **Своя** фото в музее/на улице | Возможна ст. 1276, если не «основной объект» и не извлечение прибыли | Правила музея на съёмку; монетизация поста |
| **Скачали** с сайта музея | Действуют **условия сайта** + AP на **фото/скан** музея | Раздел «некоммерческое с указанием источника» vs запрос разрешения |
| **Нашли в интернете** «в открытом доступе» | Не равно законно (п. 7 обзора ВС РФ) | Обратный поиск, лицензия CC, письмо правообладателю |
| **Купили** картину у автора | Вещь ваша, **AP у автора** (ст. 1291), если не оформлено иное | Не путать с правом постить фото для продвижения бизнеса |
| Пост **о выставке** / рецензия | Кандидат — **цитирование/обзор** (ст. 1274) + разумный объём | Имя, источник, связь с текстом |
| Реклама, мерч, обложка курса | Почти всегда нужна **лицензия** | Исключения узкие; 1276 «без прибыли» не спасает |

**Отличие от конкурентов:** не «10 сервисов проверки», а **таблица-чек-лист** + **шаблон подписи** + **блок «миф свободного интернета»** со ссылкой на ВС РФ.

## 5. action_outline

1. **Зафиксировать цель публикации:** личный архив, просветительский пост, новость о выставке, реклама услуг/товаров, продажа принтов — от цели зависит применимость ст. 1274, 1276 и необходимость лицензии.
2. **Идентифицировать картину:** автор, год, дата смерти автора (или пометка «современник»); при сомнении — справочник музея/каталог; если смерть **более 70 лет назад** — перейти к шагу 4 с пометкой «работа в общественном достоянии» (ст. 1281–1282).
3. **Определить источник файла:** собственная съёмка; официальный сайт музея; маркетплейс/фотобанк; соцсеть или агрегатор — для каждого варианта свой блок рисков.
4. **Проверить права на фото/скан:** если файл не ваш — найти правообладателя (подпись на сайте, EXIF, обратный поиск); для музейных JPG — открыть раздел «copyright» / «использование материалов».
5. **Сверить с исключениями ГК:** при обзоре выставки — ст. 1274 (объём, имя, источник); при своей съёмке в зале — ст. 1276 (не основной объект рекламы, нет извлечения прибыли); **не** применять ст. 1276 к скачанному из интернета файлу (п. 7 обзора ВС РФ).
6. **Проверить договор/правила площадки:** политика музея (некоммерческое с атрибуцией vs письменный запрос); правила съёмки в зале (запрет вспышки ≠ запрет AP, но может быть запрет коммерческой съёмки).
7. **При охраняемой работе или чужом фото:** получить **письменное** разрешение или лицензию (в т.ч. CC с подходящими условиями); сохранить скрин/договор.
8. **Подготовить подпись:** автор картины, название, год, коллекция/музей; для файла — автор снимка и URL источника (по мотивам [tretyakovgallery.ru](https://www.tretyakovgallery.ru/about/copirith/)).
9. **Зафиксировать решение в чек-листе:** «основание публикации» (общественное достояние / 1274 / 1276 / лицензия №… / отказ — заменить изображение); при отказе — подобрать работу из PD или сток с лицензией.

## 9. Риски для writer

- Не строить статью вокруг **«изменений 2026»** из SEO-клонов без нормы ГК.  
- Не обещать, что **некоммерческий** блог всегда вне риска (1274 — узкий объём; реклама в профиле может быть коммерцией).  
- Не путать **ст. 1276** (съёмка на месте) и **скачивание** с сайта.  
- Осторожно с **«простой репродукцией без AP»** — спорная зона; не давать бинарного «скан музея = всегда можно».  
- Цифры компенсации — только **ст. 1301** (10 тыс. – 10 млн руб., ред. 2026), не «5 млн» из рекламных сниппетов.  
- Без эмодзи; дисклеймер «не юруслуга»; CTA lireate — мягкий (консультация по ИС), без обещания «100% защиты».
