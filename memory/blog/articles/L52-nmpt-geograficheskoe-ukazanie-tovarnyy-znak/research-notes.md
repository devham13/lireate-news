1. **Классифицировать цель (H2-1):** нужен **бренд** (ТЗ), **коллективная защита региона** (ГУ/НМПТ) или только **честная этикетка** «произведено в…» без исключительного права на топоним.  
2. **Сверить определения (H2-2):** по ст. 1516 — стадии производства (одна vs все), «характеристики» vs «особые свойства»; выписка из [гл. 76](https://www.consultant.ru/document/cons_doc_LAW_64629/be8fc5b6a0661d4daf083041900996da0c8d91b7/).  
3. **Поиск в реестрах (H2-4, частично H2-6):** [fips.ru/registers-web](https://www.fips.ru/registers-web/) — реестр ГУ/НМПТ и заявок; [searchplatform.rospatent.gov.ru/trademarks](https://searchplatform.rospatent.gov.ru/trademarks) — ТЗ и заявки с топонимом; зафиксировать номера и классы товаров.  
4. **Тест экспертизы ТЗ (H2-3):** по перечню МКТУ — **фантазийный** топоним vs **место производства** (рек. № 39); есть ли охраняемые **ГУ/НМПТ** → п. **7** ст. 1483; адрес заявителя ≠ регион → риск **п. 3** ст. 1483.  
5. **Если нужен НМПТ/ГУ (H2-4):** собрать объединение / заключение органа субъекта (НМПТ), бюджет пошлин 3k+13k+18k (×0,7 online); образцы на [rospatent.gov.ru/forms](https://rospatent.gov.ru/ru/docs/form/forms).  
6. **Если нужен только ТЗ (H2-3, H2-6):** спланировать неохраняемый географический элемент, переработку доминирующего топонима, сужение перечня; при п. 7 — путь **неохраняемого элемента** только при **праве использования** НМПТ/ГУ.  
7. **Маркировка в обороте (H2-5):** отличить **знак охраны** (ст. 1520) от «фальшивого» происхождения; не использовать «зарегистрированное НМПТ» без права из реестра.  
8. **До подачи (H2-6):** пройти чек-лист (таблица ниже для writer); при риске отказа — [L01](внутренняя ссылка Lireate); при уведомлении с п. 7 — [L07](внутренняя ссылка Lireate); при споре с чужим ТЗ — L08.
