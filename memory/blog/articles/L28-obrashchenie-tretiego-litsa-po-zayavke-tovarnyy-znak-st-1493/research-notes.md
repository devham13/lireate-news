## 1. SERP-обзор (WebSearch Cursor + research-serp.json, ноябрь 2026)

**Паттерн выдачи:** запрос «**возражение на заявку** на товарный знак» в Яндексе/Google тянет **три разные процедуры**: (1) **обращение** на экспертизе (**ст. 1493** — до решения о регистрации, без пошлины 2.28.4), (2) **возражение против предоставления правовой охраны** уже зарегистрированному знаку (**ст. 1512–1513**, ППС, **14 000 ₽**), (3) **возражение заявителя** на отказ по **своей** заявке (**ст. 1500**). Конкуренты (vitvet, lyratetrademark, 1patent.ru, подборки КонсультантПлюс) часто пишут «**3 месяца** с публикации» для ст. 1493 — **в ГК РФ и Правилах № 482 такого срока нет**; не переносить в L28.

**Пробел Lireate (L28):** узкий **workflow только по ст. 1493**: когда окно открыто (публикация в бюллетене → до решения по экспертизе), **кто** может подать (**любое лицо**, не только «заинтересованное»), **куда** (Роспатент/ФИПС, каналы подачи), **что** указать (номер заявки, доводы по **ст. 1477 и 1483**, доказательства), **что дальше** (учёт при экспертизе, без заседания ППС), **когда лучше подождать** и идти в **1512–1513** (ссылки на L08 / L21 без дублирования их гайдов).

## 4. Угол L28 (utility)

**Главный угол:** пошаговый гайд **только** для **обращения по ст. 1493** — от обнаружения заявки в бюллетене/реестре до отправки в Роспатент и понимания **исхода на экспертизе**, с **развилкой**: «успели до решения → 1493» / «уже свидетельство или пропустили окно → L08 (1512–1513)».

**Отличие от L08:** L08 = две дороги + ППС + календарь заседания; L28 = **глубина по одной дороге** (1493): содержание, доказательства, каналы, **нет 14 000 ₽**, **нет коллегии**.

**Отличие от L21:** L21 = термины и карта «оспаривания»; L28 = **инструкция подачи** обращения.

**Типичные ошибки (блок writer):** перепутали с возражением ППС; не указали **номер заявки**; подали **после** решения по экспертизе; ждали «3 месяца»; не приложили доказательства по **1483**; ожидали ответа эксперта как в ППС.

## 7. FAQ-кандидаты (короткие ответы-действия)

1. **Куда подаётся «возражение» на заявку?** → В **Роспатент** (Бережковская наб., 30-1; почта ГСП-3 125993) теми же способами, что документы по заявке ([госуслуга](https://rospatent.gov.ru/ru/stateservices/gosudarstvennaya-registraciya-tovarnogo-znaka-znaka-obsluzhivaniya-kollektivnogo-znaka-i-vydacha-svidetelstv-na-tovarnyy-znak-znak-obsluzhivaniya-kollektivnyy-znak-ih-dublikatov), [п. 9 Правил № 482](https://www.consultant.ru/document/cons_doc_LAW_184868/354796ff2127929e8ba2ec52fa49605433f56508/)).

3. **Кто может подать — только заинтересованный?** → По **1493** — **любое лицо**; «заинтересованное» — для части оснований **1513** после регистрации.
4. **Есть ли срок «3 месяца»?** → В **ГК/Правилах № 482** для 1493 **не установлен**; ориентир — **до решения** по экспертизе.
5. **Получу ли ответ эксперта?** → Не обязаны вести переписку; доводы **учитываются** при экспертизе ([ст. 1499](https://www.consultant.ru/document/cons_doc_LAW_64629/42114f8819a5a871c211331ca2b2d5ae1ebda818/)).
6. **Что если уже выдали свидетельство?** → Окно 1493 закрыто → **1512–1513**, см. L08.
