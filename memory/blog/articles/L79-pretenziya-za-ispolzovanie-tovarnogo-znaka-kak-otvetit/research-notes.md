## 6. action_outline (маппинг на H2)

1. **Сохранить претензию** (оригинал, трек, скрины сайта/карточек); зафиксировать, **что именно** вменяют: товар, домен, вывеска, маркетплейс (п. 2 ст. 1484).
2. **Проверить отправителя:** совпадение с правообладателем в [реестре ФИПС](https://www.fips.ru/registers-web/) / [Поисковой платформе](https://searchplatform.rospatent.gov.ru/trademarks); запросить доверенность/лицензию, если пишет представитель (см. L75 — только если цепочка права неясна).
3. **Проверить охрану:** статус регистрации, срок, переходы права, **точный перечень** товаров/услуг в свидетельстве (не только номер класса МКТУ).
4. **Сопоставить деятельность:** однородность по критериям ВАС/ППВС; аргумент **неоднородности** с фактами (ассортимент, канал, аудитория); при оригинале товара — пакет под **ст. 1487**.
5. **Разобрать способ использования:** совпадает ли вменяемое действие с охраняемым способом; при описательном использовании — п. 157 ППВС № 10.
6. **Проверить сумму:** какой способ п. 4 ст. 1515 заявлен; есть ли расчёт и документы; контррасчёт; для глубины — [L76](`/internal-path/` (slug уточнить по published-articles).
7. **Выбрать позицию:** отказ с перечнем недостающих доказательств / частичное исполнение (убрать знак с носителя) без признания компенсации / предложение переговоров.
8. **Направить письменный ответ** до срока из претензии и/или с учётом **30 дней** по п. 5.1 ст. 1252; оформление — **L02**; сохранить доказательство отправки.
