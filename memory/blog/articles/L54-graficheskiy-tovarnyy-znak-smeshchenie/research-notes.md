## 4. Угол и дифференциация

**Главный угол:** «**Диагностика и смягчение визуального сходства до подачи**» — подготовить файлы (полный знак + графика без текста) → Поисковая платформа (изображение + Вена) + выборочно реестр **заявок** (L01) → для каждого «красного» знака таблица по **5 признакам п. 43** + однородность (п. 45) → блок **приёмы доработки** (силуэт, симметрия, образ, стиль, палитра, композиция) → решение: доработать и подать / письмо-согласие / сузить классы / предоценка ФИПС / поверенный.

**Отличие от конкурентов:** не общий ликбез «что такое смешение», а **troubleshooting-матрица** «признак совпал → что менять в AI/Figma» + явная **граница** «доработка до подачи» vs «уже подали — см. L07/L39».

**Тон Lireate:** патентные поверенные; CTA мягкий на `reg-tz-main`.

**H2-каркас (предложение writer):**

1. Когда графический знак «красный» уже на этапе макета (связка с L01).  
2. Как искать: изображение, Вена, заявки.  
3. Пять признаков п. 43 — таблица самопроверки.  
4. Комбинированный знак: что сравнивает эксперт (п. 44, доминанта).  
5. Однородность и «серые» классы.  
6. Приёмы снижения риска (доработка элемента).  
7. Когда хватает правки, а когда — новая заявка (1497).  
8. Письмо-согласие, предоценка, поверенный.  
9. FAQ.

**Объём:** 8 500–9 500 знаков текста.

## 5. action_outline

1. Экспортировать **два JPG**: полное обозначение и **только графический элемент** (без слов); для платформы — ориентир **до 3 МБ**, TIFF при необходимости.
2. Зафиксировать классы **МКТУ-13–2026** и черновой перечень товаров/услуг (отсылка к L01, без повтора классификатора).
3. В [Поисковой платформе](https://searchplatform.rospatent.gov.ru/trademarks): вкладка **«Изобразительный»**, поиск **по изображению**; повторить с «только графика»; дополнительно — коды **Венской классификации**.
4. Отобрать 5–15 ближайших знаков: номер, статус, классы, ссылка на реестр; отдельно проверить **реестр заявок** по номерам из выдачи.
5. По каждому кандидату заполнить таблицу **п. 43** (форма, симметрия, смысл, характер, цвет) и отметить **первое впечатление** «можно перепутать?».
6. Для **комбинированного** макета: выделить доминирующий элемент (размер, центр, контраст) и повторить оценку по п. 44.
7. Проверить **однородность** перечней (п. 45); при сомнении — лексико-семантический идентификатор (L01).
8. При совпадении 2+ признаков в однородных классах — **план доработки** (п. 6): изменить силуэт/симметрию, сменить образ или стиль, перестроить композицию, скорректировать палитру; перезапустить п. 3–5.
9. Принять решение: **подавать** доработанный знак / **письмо-согласие** (п. 46) / **сузить МКТУ** / **предоценка ФИПС** 46 200 ₽ / эскалация поверенному; если меняется доминирующая графика — готовить **новую заявку** (ст. 1497), а не «вписать» в старую.
